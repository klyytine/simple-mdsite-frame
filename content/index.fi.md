# Tervetuloa

Tämä on etusivu. Muokkaa tekstiä tiedostossa `content/index.fi.md`.

Vasen palsta on valikko. Se tulee tiedostosta `settings.json`.
Oikea palsta näyttää sivun tiedot tämän tiedoston alun front matterista.

## Mitä voit kirjoittaa

- Otsikot merkeillä `#`, `##`, `###`
- Listat merkillä `-`
- **Lihavointi** muodossa `**lihavointi**`
- Linkit muodossa `[teksti](https://example.com)`
- Taulukot, katso `example-project.fi.md`
