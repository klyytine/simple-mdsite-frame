# Tietosuoja

Sivustolla ei ole analytiikkaa, evästeitä, lomakkeita eikä JavaScriptia.

Palveluntarjoaja (esimerkiksi GitHub Pages) voi tallentaa teknisiä lokeja, kuten IP-osoitteita.
Katso palveluntarjoajan oma tietosuojaseloste.

Päivitä tämä sivu, jos lisäät jotain, mikä kerää tietoja, kuten upotettuja videoita.
